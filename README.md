# UFODROMO — Página de Interesse

Página provisória do **UFODROMO** criada para captar pessoas interessadas no lançamento do projeto.

## 🎯 Objetivo

Permitir que visitantes:

- Conheçam o UFODROMO;
- Cadastrem nome, e-mail e WhatsApp;
- Manifestem interesse através do botão **"Tenho interesse"**;
- Recebam uma confirmação após o cadastro;
- Acessem o canal oficial do WhatsApp.

## 📋 Cadastro de interessados

Atualmente o formulário possui a estrutura necessária para receber:

- Nome
- E-mail
- WhatsApp

A próxima etapa será conectar o formulário a uma lista de interessados utilizando **Google Sheets + Google Apps Script**.

## 🚀 Execução local

Não é necessário instalar nenhuma dependência.

Basta abrir o arquivo:

```text
index.html
```

diretamente no navegador.

Para desenvolvimento, também pode ser utilizado o **Live Server** no VS Code.

## 📱 WhatsApp

Após o cadastro, o visitante poderá acessar o canal oficial do UFODROMO através do botão de entrada no WhatsApp.

O link definitivo do canal será configurado posteriormente.

## 🔒 Privacidade

Os dados fornecidos pelos interessados deverão ser utilizados exclusivamente para comunicação relacionada ao UFODROMO.

A política definitiva de tratamento dos dados será definida antes da publicação oficial do projeto.
